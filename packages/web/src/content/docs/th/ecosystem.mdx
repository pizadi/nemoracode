ชุดโครงการชุมชนที่สร้างขึ้นบน NemoraCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ NemoraCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-nemoracode](https://github.com/awesome-nemoracode/awesome-nemoracode) และ [nemoracode.cafe](https://nemoracode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
