title: "Commands"
description: "Reference for the nemoracode command line."
---

Every command accepts `--help` for its full flag list, for example `nemoracode run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ nemoracode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: NemoraCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @nemoracode/cli
      - run: nemoracode run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ nemoracode run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ nemoracode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ nemoracode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ nemoracode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ nemoracode run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ nemoracode run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ nemoracode run --auto "Fix the failing test"
```

View all subcommands and flags.

```bash
$ nemoracode run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ nemoracode mini
```

Continue the last session.

```bash
$ nemoracode mini --continue
```

Start with a model and an initial prompt.

```bash
$ nemoracode mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ nemoracode mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ nemoracode mini --help
```

## session

Manages sessions.

```bash
$ nemoracode session list
```

Limit the list and print JSON.

```bash
$ nemoracode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ nemoracode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ nemoracode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ nemoracode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ nemoracode session import session.json
```

Import into a specific directory.

```bash
$ nemoracode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ nemoracode session --help
```

## auth

Manages AI providers and credentials.

```bash
$ nemoracode auth list
```

List them as JSON.

```bash
$ nemoracode auth list --format json
```

Log in to a provider.

```bash
$ nemoracode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ nemoracode auth login anthropic --method key
```

Log out of a saved account.

```bash
$ nemoracode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ nemoracode auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ nemoracode auth export anthropic > credentials.json
$ nemoracode auth import credentials.json
```

View all subcommands and flags.

```bash
$ nemoracode auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ nemoracode mcp list
```

Add a remote server.

```bash
$ nemoracode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ nemoracode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ nemoracode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ nemoracode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ nemoracode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ nemoracode mcp logout sentry
```

View all subcommands and flags.

```bash
$ nemoracode mcp --help
```

Manages plugins.

```bash
$ nemoracode plugin list
```

```bash
$ nemoracode plugin list --builtin
```

```bash

```

Check package plugins for updates.

```bash
$ nemoracode plugin check
```

```bash

```

Remove a plugin from global configuration.

```bash
$ nemoracode plugin remove @example/nemoracode-tui
```

View all subcommands and flags.

```bash
$ nemoracode plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ nemoracode serve
```

Bind to all interfaces on a fixed port.

```bash
$ nemoracode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ nemoracode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ nemoracode serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ nemoracode pair
```

Use an external URL in the links.

```bash
$ nemoracode pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ nemoracode pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ nemoracode pair --remote --yes
```

View all subcommands and flags.

```bash
$ nemoracode pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ nemoracode service start
```

Restart it.

```bash
$ nemoracode service restart
```

Show its status.

```bash
$ nemoracode service status
```

Stop it.

```bash
$ nemoracode service stop
```

Read a setting.

```bash
$ nemoracode service get hostname
```

Set a setting.

```bash
$ nemoracode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ nemoracode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ nemoracode service set env NEMORACODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ nemoracode service unset hostname
```

View all subcommands and flags.

```bash
$ nemoracode service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ nemoracode reload
```

## api

Makes a request to the running server.

```bash
$ nemoracode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ nemoracode api session.list --param limit=10
```

Send a JSON body.

```bash
$ nemoracode api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ nemoracode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ nemoracode api --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ nemoracode debug agents
```

List configuration sources.

```bash
$ nemoracode debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ nemoracode debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ nemoracode debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ nemoracode debug paths
```

Print a single path.

```bash
$ nemoracode debug paths db
```

View all subcommands and flags.

```bash
$ nemoracode debug --help
```

## upgrade

Upgrades NemoraCode to the latest or a specific version. Alias: `update`.

```bash
$ nemoracode upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ nemoracode upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ nemoracode upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls NemoraCode. Session data, configuration, and
state are not removed.

```bash
$ nemoracode uninstall
```

Preview what would be removed.

```bash
$ nemoracode uninstall --dry-run
```

View all subcommands and flags.

```bash
$ nemoracode uninstall --help
```
