title: "Plugins"
---

Add published packages, versioned packages, scoped packages, or local plugin directories to `nemoracode.json(c)`.

## Configure

```jsonc title="nemoracode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "nemoracode-acme-plugin",
    "nemoracode-acme-plugin@1.2.0",
    "@acme/nemoracode-plugin",
    "./plugins/local",
    "../shared/plugin",
    "/absolute/path/plugin",
    "file:///home/me/plugins/local",
    {
      "package": "@acme/nemoracode-plugin",
      "options": {
        "agent": "reviewer",
        "strict": true,
      },
    },
  ],
}
```

Relative paths resolve from the config file containing the entry.

Configured local paths must be directories. NemoraCode loads the directory's `server` or `index` module, such as
`index.ts`. A path to a single file is skipped.

Plugin arrays from applicable config files are applied from lowest to highest precedence instead of replacing one another.

```text
~/.config/nemoracode/nemoracode.jsonc
./nemoracode.jsonc
./.nemoracode/nemoracode.jsonc
```

## Discover

NemoraCode also loads direct `.ts` and `.js` files and immediate plugin package directories from every discovered
`.nemoracode/plugins/` directory.

```text
.nemoracode/
└── plugins/
    ├── concise.ts
    ├── reviewer.js
    └── acme-package/
```

Global plugins use the same discovery layout under the NemoraCode config directory.

```text
~/.config/nemoracode/plugins/
```

A `plugins/` directory beside a project-root `nemoracode.json(c)` is not discovered automatically; configure its plugin
directories explicitly or move it under `.nemoracode/`.

```jsonc title="nemoracode.jsonc"
{
  "plugins": ["./plugins/local"]
}
```

## Control

Plugin entries are processed in order. Prefix an ID or wildcard with `-` to disable it, use `*` for every plugin, and
use `.*` to match an ID prefix. A later ID re-enables a plugin.

```jsonc title="nemoracode.jsonc"
{
  "plugins": ["*", "-nemoracode.provider.*", "nemoracode.provider.openai", "-acme.reviewer"]
}
```

Two built-in plugins ignore removals so that a repository cannot switch off
[policy](/policies) enforcement: `nemoracode.config.policy` and
`nemoracode.provider.nemoracode`, the Console connection that delivers organization
policy.

## Manage

Install, list, check, update, or remove global package plugins with the CLI.

```sh
nemoracode plugin add nemoracode-acme-plugin@1.2.0
nemoracode plugin list
nemoracode plugin list --builtin
nemoracode plugin check
nemoracode plugin update
nemoracode plugin update nemoracode-acme-plugin
nemoracode plugin remove nemoracode-acme-plugin@1.2.0
```

`plugin check` checks server and TUI-only package plugins for updates. `plugin update` updates every outdated package;
pass a configured package target to check or update only that package. Local plugins and exact package revisions are skipped.

Package installation accepts npm names with versions, tags, or ranges, plus npm-compatible Git package specifications.
Git repositories can use hosted shortcuts, HTTPS, or SSH, including private repositories available through your existing
Git credentials.

```sh
nemoracode plugin add @acme/nemoracode-plugin@latest
nemoracode plugin add github:acme/nemoracode-plugin
nemoracode plugin add git+ssh://git@github.com/acme/nemoracode-plugin.git#main
nemoracode plugin add 'github:acme/plugins#main::path:packages/nemoracode-plugin'
```

Branches, tags, complete commit hashes, and npm's `::path:` repository-subdirectory selectors are supported. Configure
local paths directly; tarball and npm alias targets are not accepted by `plugin add`.

## Reload

Changes under watched config directories reload automatically. Server startup loads cached package plugins immediately,
installs missing packages in the background, and checks unpinned npm and Git plugins for updates without changing the
installed package. Exact npm versions and full Git commit hashes stay pinned. Changes to unwatched local dependencies may
still require restarting NemoraCode.

```sh
touch .nemoracode/plugins/concise/index.ts
nemoracode service restart
```

## Terminal

CLI-only plugins are configured separately and remain active when connected to a remote server.

```json title="cli.json"
{
  "plugins": ["nemoracode-acme-cli"]
}
```
